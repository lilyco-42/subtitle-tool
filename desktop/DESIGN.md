# 字幕工坊

目标用户不需要知道 Python、模型安装或命令行。入口按“选择视频 → 生成或导入字幕 → 校对 → 导出”组织，不能用日志或格式化文本冒充成果。

使用现有 Lain42 shadcn Base Vega 原组件与语义主题，不修改 registry 组件。工作区为视频预览、可编辑字幕文档和右侧导出控制；批量文件列表可切换，每个文件有独立字幕。视频与文本均保留在本机临时目录，清空前提示保存成果；任务历史必须可清空。

优先中文，提供键盘标签、取消、错误、空状态、明暗主题、320–1440px 布局。普通来源视频的浏览器兼容性可能受容器限制；明确提示，不假装所有格式都能原位播放。软字幕和烧录字幕的区别在导出按钮前说明。

包体、识别准确率、首次启动时间均待真实 Actions 数据，不写猜测的 39MB 或“最准”；无模型时明确提示转录尚未具备，仍允许已有字幕工作流，但不称为完整发行。
